# Shi Wa Nan Ma Shop

越南代購服飾網站（GitHub Pages 靜態網站，免費）。

- 公開網址：https://mu4540.github.io/shiwananma-shop/
- 管理頁：網址後面加 `#manage`
- 商品資料：`products.json`；照片：`photos/`
- 訂購表單：Google Form（在管理頁「網站設定」可改）

## 上架方式
1. 打開管理頁，貼上 GitHub Fine-grained Token（只需此 repo 的 Contents 讀寫權限）
2. 新增商品、上傳最多 5 張照片（自動壓縮到 1200px）
3. 儲存後約 1–2 分鐘 GitHub Pages 更新

## 讓其他人也能上架
Repo → Settings → Collaborators → 加入對方 GitHub 帳號；對方用自己的 Token 登入管理頁。

## 換 repo 或帳號
改 `index.html` 最上方的 `OWNER` / `REPO`。
